# 五类能力缺口 × 7 家供应商调研报告

> 调研日期：2026-11-04
> 背景：为 PT（PowerTokens）规划 5 类新能力接入（ASR / TTS / OCR / Embeddings·Rerank / 实时语音），先盘点 PT 现状，再调研 PT 模型页上 7 家供应商（BytePlus、MiniMax、Z.ai、Alibaba、Vidu、Kling、Mimo）各自的可替代模型与文档。

---

## 0. 一句话结论

**PT 当前 5 类能力全部缺位**（官网模型页只有视频生成、图像、chat 三类）；7 家供应商里，**Alibaba（百炼）、Z.ai（智谱）、BytePlus（火山/豆包）三家全都能覆盖 5 类**，MiniMax 缺 Embeddings/Rerank，Mimo 只有开源模型无成熟 API，Vidu 和 Kling 是纯视频公司、5 类全无。

---

## 1. PT 现状盘点

| 能力 | PT 是否有 | 说明 |
|---|---|---|
| ① ASR 语音转写 | ❌ 无 | 模型页无任何音频理解模型 |
| ② TTS 语音合成 | ⚠️ 通道在、模型缺 | `pt_gateway.py:414` 的 `audio_generate` 走 OpenAI 风格 `/v1/audio/speech` body（`model/input/voice`），但当前模型页**没有任何 TTS 模型上架**（早期接的 MiniMax Speech 已不在列表） |
| ③ OCR 文档识别 | ❌ 无专门模型 | 可用 `glm-5.3-flash` / `qwen3.8-flash`（支持图像输入）近似做 OCR，但非专用、无版面还原 |
| ④ Embeddings / Rerank | ❌ 无 | 模型页无 |
| ⑤ 实时语音 | ❌ 无 | 模型页无 |

**权威确认方式**：本机无 Key，以上基于官网模型页（powertokens.ai/models，2026-11-04 抓取）。最终以 `GET /v1/models` 实际返回为准——模型页可能只展示主打品类。

## 3. 各家明细（模型名 / 端点格式 / 文档）

### 3.1 BytePlus（字节跳动 · 火山引擎豆包系）

| 能力 | 模型 | 端点/格式 | 文档 |
|---|---|---|---|
| ASR | **Doubao-Seed-ASR-2.0**（资源 ID `volc.seedasr.sauc.duration` 小时版 / `.concurrent` 并发版） | 主力 WebSocket `wss://openspeech.bytedance.com/api/v3/...`；HTTP 方式**与 OpenAI `/v1/audio/transcriptions` 一致**（边缘网关）。支持说话人分离 `enable_speaker_info`、时间戳 `show_utterances`、情绪/性别/年龄检测、25+ 语种、粤语→简体翻译 | [一句话识别 WebSocket](https://volcengine.com/docs/DoubaoVoice/unidirectional-streaming-automatic-speech-recognition-websocket) · [调用方法（含 OpenAI 兼容映射表）](https://www.volcengine.com/docs/6893/1446852) |
| TTS | **doubao-seed-tts-2.0**（`X-Api-Resource-Id: seed-tts-2.0`） | WebSocket 双流（`/tts/bidirection`）/单流/HTTP 三种；HTTP **与 OpenAI `/v1/audio/speech` 一致** | [接入语音模型](https://www.volcengine.com/docs/ark/agent-plan-personal-voice-model) |
| OCR | **Doubao-Seed-Vision**（豆包视觉理解）+ 文字识别智能体 | chat 类多模态接口 | [调用方法](https://www.volcengine.com/docs/6893/1446852) |
| Embeddings | **Doubao-embedding / doubao-embedding-large-text**（如 `doubao-embedding-large-text-240915`） | `POST https://ark.cn-beijing.volces.com/api/v3/embeddings`，**OpenAI `/v1/embeddings` 兼容** | [文本向量化 API](https://doubao.apifox.cn/265901295e0) |
| Rerank | **doubao-seed-rerank**（多模态：文本/图片/视频混合重排，支持指令）、`base-multilingual-rerank`（70+ 语种）、`m3-v2-rerank`（100+ 语种） | 火山私有 rerank 接口 | [rerank 重排](https://docs.volcengine.com/docs/84313/2277203) |
| 实时语音 | **Doubao-RealtimeVoice**（豆包实时语音模型，超拟人对话） | Realtime API（边缘大模型网关），ASR/TTS 也都有 Realtime 调用方式 | [调用方法](https://www.volcengine.com/docs/6893/1446852) |

> 亮点：**火山是 7 家里唯一把 ASR/TTS/Embeddings 全部做成 OpenAI 兼容端点**的（`/v1/audio/transcriptions`、`/v1/audio/speech`、`/v1/embeddings`），与你提的三个建议端点几乎一一对应，接入改造成本最低。国际站 BytePlus（docs.byteplus.com）有对应英文产品线。

### 3.5 Vidu（生数科技）与 3.6 Kling（快手）

## 4. 与"建议端点"的兼容性点评

你草案里的三个端点（`POST /v1/audio/transcriptions`、`POST /v1/audio/speech`、`POST /v1/embeddings`）都是 OpenAI 通用格式。7 家的匹配度：

| 供应商 | ASR 兼容 OpenAI 格式 | TTS 兼容 | Embeddings 兼容 |
|---|---|---|---|
| BytePlus/火山 | ✅（官方文档明说与 `/v1/audio/transcriptions` 一致） | ✅（`/v1/audio/speech` 一致） | ✅（`/v1/embeddings` 一致） |
| MiniMax | ❌ 私有 `/v1/speech_to_text`（multipart，但字段功能最全） | ❌ 私有 `/v1/t2a_v2` | — |
| Z.ai | 私有（/v4 系） | 风格接近 | ❌ `/v4/embeddings`（路径不同、body 同构） |
| Alibaba | 私有 DashScope（有 OpenAI 兼容模式） | 私有 | ✅ 有 OpenAI 兼容模式 |

**含义**：如果 PT 后续真要补这 5 类能力，**BytePlus/火山的模型适配成本最低**（三个建议端点直接对得上，改 model 名即可）；MiniMax 的 ASR 功能最强但需要为它单独写一条 multipart 适配分支（类似当年 Seedance 的 media-text 特例）。

## 5. 优先级建议（对应你的排序）

1. **ASR**：首选 MiniMax asr-1.0（功能全：diarization + 字幕 + 流式，正好对齐你的需求草案）；若坚持 OpenAI 兼容格式统一，选火山 Doubao-Seed-ASR-2.0。
2. **TTS**：MiniMax Speech 2.6（业界口碑）或火山 doubao-seed-tts-2.0（OpenAI 兼容）。
3. **OCR**：Z.ai GLM-OCR（唯一专用模型 + 版面解析端点）。
4. **Embeddings/Rerank**：Z.ai embedding-3 + rerank，或火山 doubao-embedding-large + doubao-seed-rerank（后者 OpenAI 兼容）。
5. **实时语音**（后置）：火山 Doubao-RealtimeVoice / 阿里 qwen3.8-omni-flash-realtime / 智谱 GLM-4-Voice 三选一。
