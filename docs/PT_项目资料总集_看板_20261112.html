五、最终口径速查（事实卡）

开工时写代码/写数据唯一该看的一节 · 完整版见主文档 §2

鉴权与服务域

生成域 api.powertokens.ai → Bearer <API_KEY>
账户域 powertokens.ai/api → pt_live_ 个人访问令牌
OAuth 域 /oauth/* → JWT 会话凭证，不能用于 API
「access key + key id」是渠道配置字段，笔误

错误码判定

只看 error.code，不看 message（i18n 会变）
403: model_not_found / token_model_forbidden / token_group_forbidden / channel_disabled
503: model_not_found（无可用渠道，靠状态码区分）
400: invalid_request · 429: model_rate_limited

受理 / 重试（无单一信号）

非 2xx → 没受理、已退费 → 可重试
200 + JSON → 已结算 → 不可重试
200 + SSE 末帧 error/timeout/abort → 已扣费，不可重试
429：一定有 Retry-After（默认 5s），网关限流不产生费用
X-Oneapi-Request-Id 只用于报障，不是受理信号

扣费与对账

异步失败 → 同循环全额 Refund；超时 24h sweep 兜底
同步流中途 → 按已产出 token 结算扣费（total_tokens=0 才全退）
流中途记录 status=success、quota>0，用 finish_reason 过滤
失败任务：消费 + refund 负数流水成对出现、净额 0

Seedance 双接口（D5 实锤）

官方兼容：POST /byteplus/api/v3/contents/generations/tasks（content 数组，支持列表/取消）
OpenAI 风格：POST /v1/videos（media 数组，不支持列表/取消）
共用 Base URL 与 Bearer 鉴权；均需 asset://
透传也需要签协议；PT 建议走标准接口

账户接口定稿

GET /v1/logs/query 唯一；logs/list 仅兼容
分页 20/100、page 从 1；时间 Unix 秒；默认长期保留
key_id 数字主键，key_masked 脱敏串只展示
estimate 整包 {model,endpoint,key_id,request}
/v1/models 不含价格，不要自建单价表
