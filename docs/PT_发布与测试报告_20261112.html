3. 三条真机裁决（书面材料里没有的）

R1 · request_id 位置

成功响应 body 字段名 = id（48 位十六进制），与 X-Request-Id header 同值。 三个 header 分工明确；流式只在 header 回 X-Oneapi-Request-Id，但 SSE chunk 内仍有 id。

异步视频提交响应字段名仍未实测（余额不足）。

C4 · 产物有效期

图像同步标准接口返回 hailuo-image-...aliyuncs.com 的上游 OSS 签名链接， 带 Expires/OSSAccessKeyId/Signature， Expires - created = 86415s ≈ 24h。

D4「标准接口永久」不能外推到图像接口；--no-download 明确不安全。

C9 · 现行 402 报文

pre_consume_token_quota_failed + token quota is not enough, remain ＄0.005, need ＄0.034， HTTP 402、api_error、失败不扣费。

历史 403 余额报文作废由「书面裁决」升为「书面 + 真机双证」。

C1 仍待确认（不编造）：生成域 API Key 打账户域，裸值与 Bearer 两种形态返回完全一致， 差异出在凭证类型而非前缀 —— 需拿到 pt_live_ 个人访问令牌后重测。 同时真机证实现有账户命令的裸 API Key 写法确属用错凭证，为后置账户客户端（B4/B5）提供了硬证据。
C4 的适用范围：本次只实测了图像同步接口。 视频标准接口（D4 称 PT 自有地址、永久）因 Key 余额仅剩 ＄0.005 未能实测，保留书面口径； result_persistence.default_strategy 已按最保守原则收紧为「成功即下载转存」。
